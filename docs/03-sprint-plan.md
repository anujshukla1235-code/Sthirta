# 03 - Sprint Plan: Churn Prediction with Explainability & Retention Strategy

- **Sprint 0 (setup): dataset, EDA, repo scaffold**
- **Sprint 1: baseline churn model + evaluation**

## Definition of Done (per sprint)
- Code committed to GitHub with a clear commit message
- Feature manually tested against its acceptance criteria (see doc 02)
- README updated with new functionality
- No critical bugs open in that sprint's scope

## Definition of Done (project-level, end of Sprint 4)
- All "Must" and "Should" backlog items complete
- Deployed and publicly accessible (see doc 06)
- Test plan executed (see doc 05)
- Write-up ready for the portfolio site (project 10)

## Velocity Assumption
Solo developer, part-time (~10-15 hrs/week) → roughly one epic completed per sprint.
